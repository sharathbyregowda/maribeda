# Nenasu

![Nenasu Logo](public/logo.png)

A minimal, local-first diary designed for speed and privacy. Nenasu (Kannada for "Remembrance") is a zero-friction personal capture tool. Write down your thoughts, save links, and find them instantly - all without ever logging in or sending data to the cloud.

## Getting Started

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Run the development server: `npm run dev`

## Technologies

- React
- TypeScript
- Vite
